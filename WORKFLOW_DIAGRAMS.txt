API LAYER (Controllers)
═══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────────┐
│                         API ENDPOINTS                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  /api/disbursements_api.php (MODIFIED)                                      │
│  ├─ GET   → Fetch active disbursements                                      │
│  ├─ POST  → Create new disbursement                                         │
│  ├─ PUT   → Update disbursement                                             │
│  └─ POST (action=archive) → ARCHIVE DISBURSEMENT ✅ NEW                    │
│         │                                                                   │
│         ▼ Triggers:                                                         │
│         • Copy record to archived_disbursements table                       │
│         • Mark original as is_archived=1                                    │
│         • Create notification                                               │
│         • Return success                                                    │
│                                                                              │
│  /api/archived_disbursements_api.php (NEW!) ✨                              │
│  ├─ GET                    → Fetch all archived disbursements               │
│  ├─ GET (id=X)            → Fetch single archived disbursement             │
│  ├─ POST (action=retrieve) → RETRIEVE FROM ARCHIVE                         │
│  │         │                                                                │
│  │         ▼ Triggers:                                                      │
│  │         • Re-insert to disbursements table                               │
│  │         • Set is_archived=0                                              │
│  │         • Create notification                                            │
│  │         • Return success                                                 │
│  │                                                                          │
│  └─ DELETE                 → PERMANENTLY DELETE                             │
│           │                                                                 │
│           ▼ Triggers:                                                       │
│           • Delete from archived_disbursements                              │
│           • Cannot be undone                                                │
│           • Create notification                                             │
│           • Return success                                                  │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
